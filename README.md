# Fortnite Sprites Tracker

A lightweight, Fortnite-styled desktop tracker for keeping track of your **Sprites** collection, variants, levels, and mastery progress.

## Features
- **Visual Sprite Grid:** Displays all 57 sprites with custom category backgrounds and textures (**Standard**, **Fortune**, **Gold**, and **Cursed**).
- **Quick State Toggling:**
  - **Left-click** any card to cycle through **Missing → Owned → Mastered** (with mastery crown badges and borders).
  - **Right-click** an owned sprite to cycle its level (**Lvl 1 – Lvl 5**).
- **Instant Filtering & Search:** Filter by completion status (*All*, *Owned*, *Mastered*, *Missing*), variant category, or search by sprite name / `#` ID.
- **Automatic Local Saving:** Progress saves automatically between sessions.

## Download & Run (Windows)
1. Go to the [**Releases**](../../releases) section on the right.
2. Download the latest archive (`SpritesTracker-win32-x64.rar` or `.zip`).
3. Extract the entire folder and double-click **`SpritesTracker.exe`**. *(Keep all extracted files together in the same folder.)*
